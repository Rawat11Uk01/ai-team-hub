# Global conventions

- **Repo:** monorepo `ai-team-hub` with `apps/api`, `apps/web`, `infra`, `docs`, `evals`.
- **API prefix:** `/api/v1`
- **Error format:** RFC 7807 problem details.
- **Auth:** API key for early projects; JWT/session later if needed.
- **Definition of Done:** code + tests + README + one-page design doc + demo evidence.
- **Design doc must answer:** What problem? What pattern? Which tool and why?
