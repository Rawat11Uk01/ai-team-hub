# Recommended build order

1. PRD-01 → PRD-02 → PRD-03 → PRD-04
2. PRD-05 → PRD-06 → PRD-07
3. PRD-08 → PRD-09 → PRD-10

For each PRD, create a `docs/prd-XX.md` and a `docs/design-XX.md`. The PRD is the contract; the design doc is your reasoning. That keeps you aligned with the roadmap’s **Concept → Pattern → Tool** philosophy.
